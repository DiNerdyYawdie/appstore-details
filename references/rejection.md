# Common App Store Metadata Rejection Reasons

## Automatic Rejection Triggers
- Mentioning competitor app names in keywords
- Including pricing information in metadata fields
- Using Apple trademark terms in keywords (iPhone, iPad, Apple, Siri, etc.)
- Including contact information in description
- References to other platforms (Android, Google Play, etc.)
- Calls to action: Download Now, Get it Today, Buy Now
- Misleading descriptions that do not match app functionality
- Keyword stuffing in name or subtitle

## Review Rejection Triggers
- Screenshots that show features not in the current version
- Description claiming features the app does not have
- Vague or missing App Review Notes for complex features
- Missing test credentials for apps requiring login
- Description mentioning beta, coming soon, or future features

## Soft Guidelines Worth Following
- Avoid the word free in metadata if the app has any paid features
- Avoid claiming number one or best without substantiation
- Avoid using the word new to describe features that are not new
- Keep promotional text updated — stale promo text looks unprofessional

## App Review Notes Best Practices
- Always mention if the app uses on-device AI or Apple Intelligence features
- Explain any permission requests (camera, location, etc.) and why they are needed
- If the app has IAP, mention what is free vs paid
- If testing requires specific conditions, explain them clearly
