# App Store Connect Metadata Rules

## App Name
- Maximum 30 characters including spaces
- Most important field for search ranking
- Include primary keyword naturally
- No keyword stuffing — Apple will reject
- Must match your app's actual name

## Subtitle
- Maximum 30 characters including spaces
- Indexed for search — treat every word as a keyword
- Never repeat words already in the app name
- Describes the core value proposition
- Shows under the app name in search results

## Promotional Text
- Maximum 170 characters
- NOT indexed for search — purely for conversion
- Only field changeable without a new app submission
- Use for current offers, recent updates, social proof
- Never repeat what is already in the description
- Never waste it on generic descriptions

## Description
- Maximum 4000 characters
- NOT indexed for search — focus on conversion not keywords
- First 3 lines appear before the More button — make them count
- Lead with the strongest benefit, not a feature list
- Use short paragraphs, not walls of text
- No HTML or markdown formatting
- Always end with EULA line:
  We use the Apple Standard License Agreement: https://www.apple.com/legal/internet-services/itunes/dev/stdeula/

## What's New in This Version
- Maximum 4000 characters
- Describe what changed in this specific version
- Be specific — mention features added, bugs fixed, improvements made
- Base this on the latest changes found in the codebase
- Write in plain English, past tense

## Keywords
- Maximum 100 characters total including commas
- Comma separated, no spaces after commas
- Never repeat words already in app name or subtitle
- Apple indexes both singular and plural from singular — use singular
- Use all available characters — wasted space is wasted ASO
- No competitor app names
- No Apple product names (iPhone, iPad, etc.)
- Think about what your user searches for, not what you call features

## App Review Notes
- Maximum 4000 characters
- Explain anything reviewers need to know
- Include test account credentials if needed
- Describe any features that require special conditions to test
- Mention any recent changes that need reviewer attention
- Be clear and specific — vague notes slow down review
